# 配置说明

mdepuber 支持读取已有的 `book.toml`，也支持把普通文件夹当作书来构建。

## 环境变量

设置 `MDEPUB_BROWSER` 可以指定生成 PDF 时使用的 Chromium 内核：

```bash
export MDEPUB_BROWSER="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```
