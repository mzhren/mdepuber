# 导言

mdBook 会把 Markdown 编译成一本结构化的书，而 mdepuber 负责把它打包成
EPUB 或者 PDF。

## 为什么是 mdBook

| 特性 | 说明 |
| --- | --- |
| SUMMARY.md | 章节顺序与层级由它决定 |
| 预处理器 | `{{#include}}` 可以直接内联文件片段 |
| 多后端 | 同一份源文件可以输出 HTML / EPUB / PDF |

## 一段代码

```rust
fn main() {
    let title = "你好，世界";
    println!("{title}");
}
```

行内代码：`cargo build --release`。
